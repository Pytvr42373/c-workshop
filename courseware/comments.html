注释规范

// 单行 · /* */ 多行 · # vs //
🐍 Python
# 这是单行注释 x = 10 # 行尾注释 """ 这是多行注释 用三引号包裹 """
⚡ C++
// 这是单行注释 int x = 10; // 行尾注释 /* 这是多行注释 用斜杠星号包裹 */
📌 注释的区别
Python：用 # 单行注释，""" """ 多行注释
C++：用 // 单行注释，/* */ 多行注释

注释被编译器忽略，不影响程序运行。作用是给人看的。

竞赛中注释不用写太多，但关键算法思路建议注释。
💡 快捷键
大多数编辑器（VS Code、Dev-C++）支持：
Ctrl + /：把选中行变成注释（或取消注释）
不管是 Python 还是 C++ 都适用。
