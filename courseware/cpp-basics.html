💡 头文件核心知识
#include 是什么？
#include 是预处理指令，在编译前把头文件的内容原封不动地"粘贴"到你的代码里。

相当于 Python 的 import，但机制完全不同：C++ 是文本粘贴，Python 是模块加载。
<xxx.h> vs <xxx> vs "xxx.h"
<iostream> — C++ 标准头文件，无 .h 后缀
<stdio.h> — C 标准头文件，带 .h 后缀
<cstdio> — C 标准头文件的 C++ 版（把内容放进 命名空间）
"myheader.h" — 自定义头文件，用双引号
竞赛常用头文件
<iostream> — cin / cout
<cstdio> — scanf / printf
<cmath> — sqrt / pow / abs
<algorithm> — sort / min / max
<string> — string 类
<vector> — 动态数组
尖括号 vs 双引号
<iostream> 用尖括号：编译器去系统目录找
"myheader.h" 用双引号：编译器先在当前目录找，找不到再去系统目录

竞赛中几乎只用尖括号，因为用的都是标准库。
📌 竞赛小贴士
有些选手写 #include <bits/stdc++.h> 一行包含所有标准库，省去逐个写的麻烦。
但这不是标准 C++ 头文件，只在 GCC 编译器上可用。GESP 考试环境支持，但养成好习惯更好。
